# VIVACHE — ფერადი ონლაინ მაღაზია 🎨✏️📚🎁🧸

**საკანცელარიო · წიგნები · საჩუქრები · სათამაშოები** — ბათუმი, მელიქიშვილის II შესახვევი №1.

საიტი აწყობილია **akzonobelgeo**-ს სტრუქტურით და ქცევით (საიტი + მართვის პანელი + ანგარიში), ოღონდ მუშაობს **Netlify**-ზე და დაკავშირებულია **LIBRA FINANCE**-თან **Supabase**-ის გავლით — ზუსტად ისე, როგორც წინა VIVACHE აპი:

> **Libra-ში ატვირთე / შეცვალე პროდუქტი, ფასი, ფოტო ან კატეგორია → საიტზე ~1 წუთში ჩანს.**

## 2. Netlify-ზე გაშვება — ნაბიჯ-ნაბიჯ

> ⚠️ **ZIP-ის გადათრევა (Netlify Drop) არ გამოდგება** — ის ფუნქციებს (`/api`) ვერ აწყობს. გამოიყენე **A** ან **B**.

### A — GitHub-ით (რეკომენდებული: ყოველ ცვლილებაზე ავტომატური განახლება)

1. **GitHub-ზე ატვირთვა** (ერთხელ):
   ```bash
   cd vivace
   git init
   git add .
   git commit -m "VIVACHE საიტი"
   git branch -M main
   git remote add origin https://github.com/<შენი-ანგარიში>/vivache-site.git
   git push -u origin main
   ```
2. **Netlify** → [app.netlify.com](https://app.netlify.com):
   - **ახალი საიტი:** Add new site → Import an existing project → GitHub → `vivache-site`.
   - **ან არსებული `vivache.netlify.app`-ის ჩანაცვლება:** გახსენი ძველი საიტი → Site configuration → Build & deploy → **Link repository** → აირჩიე `vivache-site` (მისამართი იგივე დარჩება).
3. Build settings (`netlify.toml` თვითონ ავსებს — უბრალოდ შეამოწმე):
   - Build command: `npm run check`
   - Publish directory: `public`
   - Functions directory: `netlify/functions`
4. **Environment variables** → Site configuration → Environment variables → Add a variable:
   | ცვლადი | მნიშვნელობა |
   |---|---|
   | `ADMIN_PASSWORD` | ადმინის ძლიერი პაროლი (**სავალდებულო**) |
   | `ADMIN_SECRET` | ნებისმიერი გრძელი შემთხვევითი ტექსტი |
   | `SUPABASE_URL` | `https://xxxx.supabase.co` — იგივე, რაც Libra-ში წერია |
   | `SUPABASE_ANON_KEY` | Supabase → Project Settings → API Keys → **anon / public** |
   | `SUPABASE_SERVICE_KEY` | *(არასავალდებულო)* service_role — მხოლოდ ადმინში შეკვეთების სანახავად |
5. **Deploys → Trigger deploy → Deploy site**. ცვლადების შეცვლის შემდეგ ყოველთვის — Trigger deploy.

### B — ტერმინალიდან (Netlify CLI)

```bash
npm install -g netlify-cli
cd vivace
npm install
netlify login
netlify link            # აირჩიე არსებული „vivache“ საიტი (ან: netlify init — ახალი)
netlify env:set ADMIN_PASSWORD "შენი-ძლიერი-პაროლი"
netlify env:set ADMIN_SECRET "$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")"
netlify env:set SUPABASE_URL "https://xxxx.supabase.co"
netlify env:set SUPABASE_ANON_KEY "eyJ..."
netlify deploy --build --prod
```

> 🔒 გასაღებები და პაროლები **მხოლოდ Netlify-ში** ჩაწერე — არა კოდში, არა git-ში, არა ჩატში.

## 3. Supabase-ის პარამეტრები (ერთხელ)

ბაზა (ცხრილები და `vv_*` ფუნქციები) უკვე არსებობს — Libra მასთან მუშაობს. საჭიროა მხოლოდ:

1. **განახლებები:** დარწმუნდი, რომ SQL Editor-ში გაშვებულია `buhpro/cloud/supabase.sql` და `buhpro/cloud/updates/002_payment.sql`, `003_payment_proof.sql` (ქვითრის ატვირთვისთვის). თავიდან გაშვება უსაფრთხოა.
2. **Authentication → URL Configuration:**
   - **Site URL:** `https://vivache.netlify.app` (ან შენი დომენი)
   - **Redirect URLs:** დაამატე `https://vivache.netlify.app/account` (და დომენის შემთხვევაში — `https://vivache.ge/account`)
   — ამის გარეშე დადასტურების/აღდგენის წერილის ბმული საიტზე ვერ დაბრუნდება.
3. **Authentication → Providers → Email:** ჩართული იყოს „Confirm email“ (რეგისტრაცია ელფოსტის დადასტურებით, როგორც akzo-ზე).
4. *(სურვილისამებრ)* **Authentication → Email Templates** — წერილის ტექსტი ქართულად.
5. **სტუმრის შეკვეთა:** Libra → ონლაინ მაღაზია → პარამეტრები → ✅ „შეკვეთა ანგარიშის გარეშეც (სახელი + ტელეფონი)“.

## 7. შავი პარასკევი, ახალი წელი, ქეშბექი

**⚡ შავი პარასკევი** — ადმინი → აქციები → **ჩართვა**: ზოლები შავ-ყვითელში, ტაიმერი, ზოლში ფასდაკლებული პროდუქცია. **ფასდაკლება** Libra-ში (ფასების სია) — ასე საიტი და სალარო ერთ ფასს აჩვენებს; საიტზე გადახაზული ფასისთვის პროდუქციაში ჩაწერე „ძველი ფასი“.

**🎄 ახალი წელი** — ადმინი → საახალწლო რეჟიმი:
- ❄️ თოვლი, 💡 მოციმციმე გირლიანდა, თოვლი ლოგოზე
- 🎅 სანტა ირმებით ჩაუფრენს ეკრანს (~40 წამში ერთხელ), დააჭირე — კონფეტი
- 🧝 ელფები კუთხეებიდან იხედებიან და ხელს გიქნევენ
- 🎵 მუსიკა: Jingle Bells → We Wish You a Merry Christmas → Deck the Halls → Silent Night — **თავისით იცვლება**. მელოდიები საჯარო საკუთრებაა (public domain) და ბრაუზერში სინთეზირდება — ფაილები და საავტორო უფლებები არ სჭირდება. ბრაუზერი ხმას მხოლოდ დაჭერის მერე უშვებს, ამიტომ ირთვება 🎵 ღილაკით.
- ⏳ ტაიმერი „ახალ წლამდე“

**💳 ქეშბექი** — Libra-ს ბარათი და ბალანსი ჩანს კაბინეტში (შტრიხკოდით, სალაროში დასასკანერებლად); შეკვეთისას „გადავიხდი ქეშბექით“ (ლიმიტი Libra-ს ბარათის ტიპით). ჯავშანი და ჩამოჭრა — Libra-ში, როგორც აქამდე.

## 8. ლოკალურად გაშვება და ტესტი

## 12. უსაფრთხოება

- ბრაუზერი Supabase-ს მხოლოდ ჩვენი ფუნქციის გავლით ეკონტაქტება; anon key-ს RLS ზღუდავს — ჩანს მხოლოდ აქტიური პროდუქცია/კატეგორიები და საჯარო პარამეტრები. თვითღირებულება, მომწოდებლები, ზუსტი ნაშთი საიტზე **არ მიდის** (ამას Libra-ს სინქრონიზაცია უკვე უზრუნველყოფს).
- ფასს ბრაუზერიდან არ ვენდობით — შეკვეთის ჯამს `vv_place_order` ითვლის.
- მყიდველის პაროლი ინახება მხოლოდ Supabase Auth-ში ან bcrypt ჰეშად; საიტი ინახავს მხოლოდ სესიის ტოკენს.
- ადმინის პაროლი მხოლოდ Netlify env-ში; `/admin` — noindex.
